해설 보기 · Gemini CLI v0.69~v0.71 묶음으로, /stats heatmap 서브커맨드, 독립 theme.json 지원, /model 인자 검증, 요청 타임아웃 설정 등이 추가됐고 보안·안정성 수정이 다수 포함됐다. 그 밖에 약 12건은 릴리스 노트·버전 올림·CI·의존성·테스트 등 내부 정리다.
/stats heatmap 서브커맨드
무엇 /stats 명령에 heatmap 서브커맨드가 생겨 일별 토큰 사용량을 히트맵(날짜별 사용량을 색 농도로 보여 주는 표)으로 볼 수 있다. v0.69.0에 포함됐다.
어떻게 쓰나 Gemini CLI에서 /stats heatmap을 실행한다. 그 밖의 옵션은 원문에 사용법 없음.
의미 토큰 사용 추이를 날짜별로 확인하고 싶은 사용자에게 유용하다.
출처1
독립 theme.json 커스텀 테마 설정
무엇 커스텀 테마(화면 색상 설정)를 별도의 standalone theme.json 파일로 구성할 수 있게 지원한다. 테마 파일의 홈 디렉터리 위치 검사도 isSubpath로 바꿔 보완했다.
어떻게 쓰나 원문에 사용법 없음. 파일 위치와 형식은 원문에 없다.
의미 터미널 색상을 직접 꾸미는 사용자에게 의미가 있고, 나머지는 몰라도 된다.
출처1
/model 명령 인자 검증과 모델 목록 정확도 개선
무엇 /model 명령이 모델 이름을 검증하고 직접 인자로 받는 방식을 지원한다. v0.70.0에서는 models list가 정확한 출력 토큰 한도를 보고하고, 인증 기능 초기화와 옵션 중복 제거도 고쳤다.
어떻게 쓰나 /model 뒤에 모델 이름을 직접 붙여 쓴다. 구체적인 예시는 원문에 없다.
의미 모델을 자주 바꾸는 사용자에게 편하고, 잘못된 이름을 입력했을 때 걸러 준다.
출처1 · 출처2
API 헤더·요청 타임아웃 조정
무엇 기본 60초인 API 헤더 타임아웃을 모든 인증 방식에서 덮어쓸 수 있게 했다(v0.69.0). 요청 타임아웃이 기본 300초를 넘으면 undici(Node.js HTTP 클라이언트)의 bodyTimeout도 함께 늘어나도록 고쳤다(v0.70.0). 네트워크 실패 시 로딩이 수 분간 멈추거나 쿼터 재시도가 수 시간 이어지던 문제도 수정했다.
어떻게 쓰나 설정 model.requestTimeoutMs 또는 환경 변수 GEMINI_API_HEADERS_TIMEOUT_MS로 지정한다.
의미 응답이 느린 환경이나 긴 요청을 쓰는 사용자에게 의미가 있다.

Gemini 4 Neon
무엇 Google DeepMind가 내놓은 모델이다. 복잡한 소프트웨어 엔지니어링, 지식 업무, 과학 워크플로에서 빠르게 작업을 끝내는 데 초점을 둔다. 컨텍스트 창은 100만 토큰이다. 가격은 입력 100만 토큰당 $3(캐시 입력 $0.15), 출력 100만 토큰당 $15다. 생각 수준(thinking level)은 4단계이고 기본값은 high다. 원문은 Carbon보다 작업당 비용이 32% 낮다고 밝힌다.
어떻게 쓰나 Gemini API(Google AI Studio)와 Gemini for business(API 및 모델 드롭다운)에서 쓸 수 있다. 유료 Google AI Pro·Ultra 구독자는 Google Antigravity에서, Pro·Ultra 구독자는 Gemini 앱 모델 드롭다운에서도 쓴다. Android Studio에서도 시작할 수 있다. 사이버 방어용 Neon for cyber는 Fairwind Program을 통해 신뢰된 방어자에게 곧 제공된다.
의미 코딩 에이전트나 장시간 에이전트 작업을 만드는 개발자에게 의미가 크다. Antigravity에서 /swarm으로 Hydrogen 하위 에이전트를 지휘하는 오케스트레이터로도 쓸 수 있다. 비용과 성능을 thinking 수준으로 조절할 수 있다.

Gemini 앱 Mac용 computer use
무엇 Mac용 Gemini 앱이 로컬 파일, 데스크톱 앱, 웹에서 여러 단계로 이뤄진 반복 작업을 대신 처리한다. 클릭, 입력, 메뉴, 양식 입력을 맡는다. 별도의 격리된 백그라운드 창에서 돌아가므로 사용자의 화면과 커서는 자유롭다. 채팅에서 실시간 미리보기를 볼 수 있다.
어떻게 쓰나 gemini.google/mac에서 앱을 내려받는다. 접근을 허용할 앱을 직접 고르고, 모든 단계를 지켜보며, 언제든 일시 중지하고, 주요 동작은 실행 전에 승인한다. 현재는 미국 영어만 지원한다. Apple Silicon Mac과 macOS Sequoia 15.0 이상이 필요하다. 만 18세 이상 개인 Google 계정이어야 하고 Google AI Plus, Pro, Ultra 사용자가 쓸 수 있다.
의미 사진 일괄 색보정, PDF 정보를 배송 견적 양식에 옮기기, 대시보드 지표로 Slides 만들기 같은 반복 업무를 줄이고 싶은 Mac 사용자에게 의미가 있다.
출처1
Genie 4와 Project Genie 업데이트
무엇 Project Genie에 Genie 4 모델이 추가됐다. 세계를 탐색하는 도중 프롬프트로 날씨, 캐릭터 등을 실시간으로 바꿀 수 있고, 장면에 맞춰 변하는 네이티브 오디오도 나온다. Genie 3는 세션이 최대 3분(기존 60초)으로 늘고 월드 연결, 360도 파노라마 이미지 기반 생성을 지원한다. 대화로 월드를 만드는 Project Genie agent와, 월드를 공유·리믹스하는 커뮤니티 갤러리도 생겼다.
어떻게 쓰나 Project Genie 웹사이트에서 쓴다. 자격이 되는 Google AI Ultra 구독자는 오늘부터 쓸 수 있고, Google AI Pro 회원은 같은 페이지에서 대기자 명단에 등록한다. 모델 선택기에서 Genie 3와 Genie 4를 고른다. 생성된 영상과 오디오에는 SynthID 워터마크가 들어간다.
의미 월드 모델과 인터랙티브 콘텐츠를 실험하려는 Ultra 구독자에게 의미가 있다. 관련 글 제목에 'Genie 4 is now available on the Gemini API'가 있으나 이 묶음에는 원문이 없다.

Search Personal Intelligence에 앱 연결 확대
무엇 AI Mode의 Personal Intelligence에 Google Wallet 연결이 오늘부터 시작된다. Drive와 Gemini 앱 연결은 몇 주 안에 이어진다. 기존 Gmail, Calendar, Photos에 더해 지출, 문서, 대화 맥락으로 맞춤 답변을 받는다. Wallet 연결은 읽기만 가능하고 돈을 옮기거나 관리·투자할 수 없다. 최근 검색 맥락에 맞춘 답변도 AI Overviews와 AI Mode에 늘어난다.
어떻게 쓰나 Search Personalization에서 Connected Apps를 열고 연결할 앱을 고른다. 연결은 언제든 켜고 끌 수 있다. 맞춤 답변을 고치려면 스레드에서 "I'm no longer a vegetarian"처럼 알려주면 된다. 응답 아래 'Personalization' 아이콘으로 쓰인 맥락을 확인하는 기능은 곧 추가된다.
의미 개발자 기능은 아니고 Search 사용자에게 해당한다. 개인정보 연결은 직접 선택해야 켜진다.

Connected Apps 확대와 Gemini 4 Hydrogen
무엇 미국에서 Search와 Gemini 앱에 식료품 Connected Apps(Albertsons, Safeway, Shaw's, Target)가 추가된다. Universal Commerce Protocol 기반이다. Experian은 Search에서도 신용 등급 확인과 개인 대출 비교를 제공한다. H&R Block은 세금과 환급 예상 계산을 맡는다. Angi와 Thumbtack은 몇 주 안에 연결된다. 별도로 Gemini 4 Hydrogen은 Carbon과 함께 쓰는 빠른 실행용 모델이다.
어떻게 쓰나 Hydrogen은 Google AI Studio와 Android Studio의 Gemini API에서 쓴다. Google AI Pro·Ultra 유료 구독자는 Google Antigravity에서도 쓴다. 누구나 Gemini 앱 드롭다운, Google Search, Gemini for business에서 쓸 수 있다. 무료 사용자는 자동 모델 선택으로 접한다. Connected Apps는 미국에서 제공된다.
의미 Hydrogen은 Antigravity의 /swarm에서 Carbon이 지휘하는 작업자로 쓰인 사례가 있다. Connected Apps는 미국 사용자용 쇼핑·금융 기능이다.

해설 보기 · modelcontextprotocol/servers v2.5.0은 mcp-server-git, server-filesystem, server-everything의 보안 취약점 8건을 고친 보안 릴리스다. 모든 참조 서버가 Streamable HTTP도 지원하게 됐고, memory 서버에는 쓰기 제한 옵션이 들어갔다. 그 밖에 문서·CI·의존성 정리 등 내부 변경이 있다.
mcp-server-git 2026.11.18 보안 수정 6건
무엇 저장소 설정이 서버 권한으로 외부 프로그램을 실행하게 만들 수 있던 문제들을 막았다. git_merge 뒤 자동 maintenance 실행을 끄고(maintenance.auto=false, gc.auto=0), 누락된 객체의 lazy fetch를 끄고(GIT_NO_LAZY_FETCH=1), 파일을 쓴 뒤 filter·merge driver를 다시 읽는다. 빈 이름 driver도 비우고, 작업 트리 밖을 가리키는 index 항목을 거부하며, submodule 설정이 프로그램을 실행하지 못하게 했다.
어떻게 쓰나 mcp-server-git를 2026.11.18로 올린다. 설정할 것은 없다. 낡은 Git에서는 promisor remote가 선언된 저장소나, submodule을 체크아웃한 저장소(Git 2.33 미만)를 거부한다. --repository 제한 검사는 쓰기 뒤에 아직 반복되지 않는다(#5599).
의미 신뢰할 수 없는 저장소를 mcp-server-git로 다루는 사용자는 바로 업그레이드해야 한다. 영향 범위는 2026.11.11까지의 버전이다.

server-filesystem 2.4.0: 디렉터리 목록 검사 우회 수정
무엇 list_directory, list_directory_with_sizes, directory_tree, search_files가 디렉터리를 검사한 뒤 같은 디렉터리를 그대로 나열한다. 검사와 나열 사이에 디렉터리를 symlink로 바꿔치기해도 허용 디렉터리 밖의 항목 이름이 반환되지 않는다. 이 보호는 Linux와 macOS에만 적용되고, Windows는 아직 고정되지 않았다(#5600).
어떻게 쓰나 날짜 버전(2025.x, 2026.x) 사용자는 패키지 관리자가 2.4.0을 업그레이드로 제안하지 않는다. 직접 설치해야 한다: npm install @modelcontextprotocol/server-filesystem@2.4.0
의미 filesystem 서버를 쓰는 사용자에게 의미가 있다. 날짜 버전을 쓰고 있다면 명시적으로 설치해야 한다. Windows에서는 이 수정이 적용되지 않는다.

server-everything 2.3.1: NAT64 주소로 사설 IP 접근 차단
무엇 gzip-file-as-resource 도구의 사설 주소 차단 로직이 64:ff9b::/96 대역(NAT64)을 공개 주소로 잘못 판단했다. NAT64 게이트웨이가 있는 네트워크에서는 이를 통해 사설 IPv4 주소에 닿을 수 있었다. 이제 내장된 IPv4 주소를 검사한다.
어떻게 쓰나 @modelcontextprotocol/server-everything을 2.3.1로 올린다.
의미 NAT64 환경에서 이 테스트용 참조 서버를 쓰는 경우에만 해당한다. 그 외에는 몰라도 된다.

출처1
memory 서버 쓰기 제한 옵션과 lock 처리 개선
무엇 server-memory 2.2.1에 그래프 크기에 대한 opt-in 쓰기 제한이 추가됐다(#5534). 종료나 SIGINT/SIGTERM 때 잡고 있던 lock 파일을 풀고, stale lock을 깰 때 다른 프로세스의 살아 있는 lock을 지우지 않게 했다. Streamable HTTP 서버가 멈출 때도 lock을 푼다.
어떻게 쓰나 원문에 사용법 없음. 쓰기 제한은 선택 사항(opt-in)이라는 설명만 있고, 설정 이름은 적혀 있지 않다.
의미 memory 서버를 장기간 돌리거나 여러 프로세스에서 쓰는 사용자에게 도움이 된다.
