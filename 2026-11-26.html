샌드박스·Assisted Permissions 개선
무엇 샌드박스 설정이 늘었습니다. Windows sandbox 패키지 조회가 기본 활성화됐고, macOS Mach service 조회를 따로 허용할 수 있으며, 여러 worktree가 있는 저장소에서도 Git add/commit이 허용됩니다. 1.0.116에서는 Swift, Bun 캐시 접근이 허용되고 세션 plan도 읽을 수 있습니다. 샌드박스가 명령을 막으면 정책상 가능할 때 세션 동안 샌드박스 해제를 안내합니다. Assisted Permissions는 승인 철회 반영, 더 구체적인 사유 제시, 더 빠른 처리가 개선됐습니다.
어떻게 쓰나 Windows 패키지 조회를 끄려면 sandbox.userPolicy.capabilities를 []로 설정합니다. macOS는 sandbox.userPolicy.seatbelt.extraMachLookups로 허용하며 Keychain 접근은 켜지 않습니다. /sandbox policy로 sandboxed gh가 쓰는 GitHub 계정을 확인합니다.
의미 샌드박스에서 에이전트를 돌리는 개발자와 권한 승인 프롬프트가 잦은 사용자에게 의미가 있습니다.

무엇 탠덤 질량분석(MS/MS) 스펙트럼에서 분자 구조를 추정하는 Antigravity용 skills 모음이다. 에이전트가 matchms, GNPS·MoNA 라이브러리 검색, SIRIUS, MAGMa, MetFrag, RDKit 같은 공개 도구를 연쇄 실행하고 PubChem을 조회한다. 그 결과를 근거와 함께 검토 가능한 보고서로 정리한다.
어떻게 쓰나 Google Antigravity에서 작업과 기기 허용 오차를 평범한 말로 적으면, 에이전트가 필요한 skill을 골라 연결한다. 노이즈 제거, 라이브러리 검색, 분자식 결정, 후보 이성질체 비교 같은 단계도 따로 실행할 수 있다. 설치 방법은 원문에 없다.
의미 분석화학·천연물 신약 연구자에게 의미가 있다. 그 밖의 개발자에게는 Antigravity skills로 외부 도구를 묶는 사례 정도다.
