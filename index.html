Copilot code review 청구 기본값이 조직으로 변경
무엇 Copilot Business·Enterprise에서 Copilot code review 청구 방식을 따로 고르지 않았다면, 2026년 12월 30일부터 라이선스가 있는 멤버의 리뷰 비용이 저장소를 소유한 조직에 청구된다. 지금은 멤버의 Copilot 사용 권한(entitlement)이 쓰인다. 이미 Member나 Organization을 골랐다면 그대로 유지된다.

의미 조직 청구에는 AI Credits 유료 사용이 필요하고 조직 지출이 늘 수 있어, 관리자는 12월 30일 전에 확인해야 한다. AI Credits 유료 사용이 꺼져 있거나 청구 잠금이 있거나 청구 대상 고객이 없으면 Member로 설정된다.

Copilot CLI sandbox 설정·호환 확대
무엇 sandbox(격리 실행 환경)에서 쓸 수 있는 범위가 넓어졌다. 1.0.116에서는 env 설정으로 Copilot이 시작하는 모든 프로세스(셸 명령, LSP·MCP 서버, hook, extension)에 환경 변수를 줄 수 있다. Swift와 Bun 도구의 캐시 사용도 허용됐다. 1.0.115에서는 Windows sandbox 패키지 조회가 기본 활성화됐고, macOS Mach service 조회를 허용하는 설정이 추가됐다.
어떻게 쓰나 env 설정으로 환경 변수를 지정한다(sandbox 사용 여부와 무관). Windows 패키지 조회를 끄려면 sandbox.userPolicy.capabilities를 []로 둔다. macOS에서는 sandbox.userPolicy.seatbelt.extraMachLookups로 특정 Mach service 조회를 허용한다(Keychain 접근은 켜지 않는다). /sandbox policy에서 sandboxed gh 명령이 쓰는 GitHub 계정을 볼 수 있다.
의미 sandbox를 쓰며 Swift, Bun, Rust 도구나 Git 작업이 막혀 불편했던 개발자에게 의미가 있다. sandbox가 명령을 막으면 정책이 허용할 때 세션 동안 sandbox를 끌 수 있다고 안내한다.

에이전트 팀과 Lean 검증으로 양자 알고리즘 개선
무엇 Gemini 4 에이전트 팀이 기존 양자 알고리즘을 개선했고, 결과를 Lean(형식 증명 도구)으로 수학적으로 검증했다. 관성 핵융합 계산 비용은 11.8배 줄었고 필요 큐비트는 5,650개에서 4,338개로 줄었다. Cytochrome P450은 2.5배 개선되고 큐비트가 481개에서 333개로 줄었다. Grover 구현은 2.57배, arcsin은 290배 빨라졌다.
어떻게 쓰나 Lean 라이브러리, 문제 명세, 검증된 해법이 GitHub에 오픈소스로 공개됐다. 논문과 Lean 프레임워크 링크가 원문에 있다. 구체적인 사용 절차는 원문에 없음.
의미 양자 알고리즘과 형식 검증 연구자에게 의미가 있다. 에이전트 탐색에 증명 검증을 결합하는 방식의 사례다. 일반 개발자는 몰라도 된다.
