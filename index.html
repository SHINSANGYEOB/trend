security-guidance: 안정성·메모리 개선

해설 보기 · Gemini CLI v0.69.0과 v0.70.0 릴리스 묶음이다. /stats heatmap, 커스텀 테마용 theme.json, /model 인자 검증, API 타임아웃 설정이 추가됐고, 보안·정책 평가 수정이 이어졌다. 그 밖에 다수 건은 내부 정리와 버그 수정이다.
/stats heatmap 하위 명령
무엇 /stats 명령에 heatmap 하위 명령이 생겼다. 일별 토큰 사용량을 히트맵(날짜별 농도 표시)으로 보여 준다.
어떻게 쓰나 Gemini CLI에서 /stats heatmap을 실행한다. 그 밖의 옵션은 원문에 사용법 없음.
의미 토큰 사용 추이를 날짜별로 확인하려는 사용자에게 의미가 있다.
출처1
standalone theme.json 커스텀 테마
무엇 커스텀 테마를 별도 theme.json 파일로 설정할 수 있게 됐다. 테마 파일의 홈 디렉터리 확인에는 isSubpath를 쓰도록 고쳤다.
어떻게 쓰나 원문에 사용법 없음. 파일 위치와 형식은 원문에 없다.
의미 테마를 직접 꾸며 쓰는 사용자에게 의미가 있다. 나머지는 몰라도 된다.
출처1
/model 인자 검증과 API 타임아웃 설정
무엇 /model 명령이 모델 이름을 검증하고 직접 인자를 받는다. 60초인 API 헤더 타임아웃은 모든 인증 방식에서 덮어쓸 수 있다. 요청 타임아웃이 기본 300초를 넘으면 undici bodyTimeout(응답 본문 대기 시간)도 함께 늘린다. models list는 출력 토큰 한도를 정확히 표시한다.
어떻게 쓰나 /model 뒤에 모델 이름을 바로 붙인다. 타임아웃은 설정 model.requestTimeoutMs 또는 환경 변수 GEMINI_API_HEADERS_TIMEOUT_MS로 바꾼다.
의미 응답이 느린 모델이나 네트워크 환경에서 타임아웃으로 끊기던 사용자에게 도움이 된다.
출처1 · 출처2
셸 명령·MCP 보안과 정책 평가 수정
무엇 권한이 안전하지 않은 command를 가진 시스템 MCP 서버는 건너뛴다. 확장이 풀리지 않은 셸 명령은 ASK_USER(사용자 확인)를 유지한다. commandPrefix와 commandRegex 규칙은 최상위 command 인자에 맞춰 비교한다. 정책 argsPattern 평가는 re2js를 써 선형 시간으로 처리한다. 링크 경로를 공개하고 동의 프롬프트 기본값을 no로 바꿨다. IDE 연동은 사용자별 discovery 디렉터리와 원자적 포트 파일 쓰기를 쓴다.
어떻게 쓰나 별도 설정 없이 업데이트하면 적용된다.
의미 정책 규칙과 MCP 서버를 쓰는 환경, 보안에 민감한 사용자에게 의미가 있다.
출처1
세션·입력·멈춤 관련 버그 수정
무엇 유니코드 프롬프트는 보존하고 세션 미리보기의 ANSI 조각은 제거한다. 인증 재시작 때 선택한 워크트리를 유지한다. 네트워크 장애 때 로딩이 몇 분씩 멈추는 문제와 여러 시간 이어지는 쿼터 재시도를 막는다. @file 참조의 앞뒤 공백을 보존한다. 파이프 stdin은 EOF까지 기다린다. 헤드리스 중단 때는 자식 프로세스를 종료한다. macOS에서는 PTY 파일 디스크립터 누수를 막고 Seatbelt 샌드박스 진입 전에 폴더 신뢰를 확인한다.
어떻게 쓰나 원문에 사용법 없음. 업데이트하면 적용된다.
의미 일상 사용 중 겪던 멈춤이나 입력 깨짐이 줄어든다.

해설 보기 · 최근 7일간 Gemini 공식 블로그에서는 Gemini 4 Neon 모델 공개, 일상 업무를 대신 처리하는 Task 모드, Mac용 computer use, Genie 4가 핵심이었다. Search의 Personal Intelligence 확장과 Connected Apps, 기록 이전, Canvas 활용 팁도 있었다. 그 밖에 1건(Carbon 사례 모음)은 사례 소개다.
Gemini 4 Neon
무엇 코딩·업무·과학 작업용 모델이다. 컨텍스트 창은 100만 토큰이다. 가격은 입력 100만 토큰당 $3(캐시 입력 $0.15), 출력 $15다. 사고 수준은 4단계이며 기본값은 high, 가장 깊은 단계는 xhigh다. 원문은 Carbon보다 작업당 비용이 32% 낮다고 밝혔다. 보안 전용 버전인 Neon for cyber는 Fairwind Program의 신뢰된 방어자에게 곧 제공된다.
어떻게 쓰나 Google AI Studio의 Gemini API, Gemini for business(API·모델 드롭다운)에서 쓴다. 유료 Google AI Pro·Ultra 구독자는 Google Antigravity에서, Pro·Ultra 구독자는 Gemini app에서 쓴다. 사고 수준으로 지능과 토큰 비용을 조절한다.
의미 장시간 에이전트형 코딩이나 비용 대비 성능이 중요한 개발자에게 의미가 있다. Antigravity에서는 /swarm과 Hydrogen 하위 에이전트 조율을 시연했다.
출처1
Gemini의 Task 모드(전화·결제·업무 대행)
무엇 Gemini가 전화 예약, 요금 분석, 장보기와 결제 같은 작업을 대신 처리한다. 작업은 계정 전용의 하드웨어 격리 가상 머신(Google Cloud Agent Compute Engine)에서 실행된다. 결제는 Agent Payments Protocol(AP2)을 쓰며 지출 한도를 미리 정할 수 있다. 구매 같은 중요한 단계 전에는 확인을 요청하고, 신뢰하는 작업은 "Always allow"로 지정할 수 있다. 무료 제공은 Gemini 4 Hydrogen 모델 기반이다.
어떻게 쓰나 Gemini 앱 홈 화면의 토글을 Chat에서 Task로 바꾼다. 미국에서는 gemini@google.com으로 이메일을 전달하거나 문자(설정 > Channels > Text with Gemini에서 전화번호 인증)로도 쓸 수 있다. 무료 제공 지역은 미국·일본·한국·캐나다·호주·인도이고, 고급 기능은 미국부터 제공된다. 개발자는 Connected Apps Platform에 신청할 수 있다.
의미 일상 업무 자동화에 관심 있는 사용자와 앱 연동을 하려는 개발자에게 의미가 있다.

Gemini app for Mac의 computer use
무엇 Gemini가 Mac의 로컬 파일, 데스크톱 앱, 웹을 오가며 클릭·입력·메뉴·양식 작업을 대신한다. 격리된 백그라운드 창에서 실행되고 채팅에 실시간 미리보기가 뜬다. 접근할 앱은 사용자가 고르고, 중간에 멈출 수 있으며, 주요 동작은 승인한 뒤에 실행된다.
어떻게 쓰나 gemini.google/mac에서 앱을 내려받는다. 요구 사항은 Apple Silicon Mac, macOS Sequoia 15.0 이상, 18세 이상 개인 Google 계정이며 Google AI Plus·Pro·Ultra 사용자가 쓸 수 있다. 현재는 미국에서 영어로만 제공된다.

해설 보기 · modelcontextprotocol/servers v2.5.0은 mcp-server-git, server-filesystem, server-everything의 보안 취약점 8건을 고친 보안 릴리스다. 모든 참조 서버가 Streamable HTTP도 지원하게 됐고, memory 서버에는 쓰기 제한 옵션이 들어갔다. 그 밖에 문서·CI·의존성 정리 등 내부 변경이 있다.
mcp-server-git 2026.11.18 보안 수정 6건
무엇 저장소 설정이 서버 권한으로 외부 프로그램을 실행하게 만들 수 있던 문제들을 막았다. git_merge 뒤 자동 maintenance 실행을 끄고(maintenance.auto=false, gc.auto=0), 누락된 객체의 lazy fetch를 끄고(GIT_NO_LAZY_FETCH=1), 파일을 쓴 뒤 filter·merge driver를 다시 읽는다. 빈 이름 driver도 비우고, 작업 트리 밖을 가리키는 index 항목을 거부하며, submodule 설정이 프로그램을 실행하지 못하게 했다.
어떻게 쓰나 mcp-server-git를 2026.11.18로 올린다. 설정할 것은 없다. 낡은 Git에서는 promisor remote가 선언된 저장소나, submodule을 체크아웃한 저장소(Git 2.33 미만)를 거부한다. --repository 제한 검사는 쓰기 뒤에 아직 반복되지 않는다(#5599).
의미 신뢰할 수 없는 저장소를 mcp-server-git로 다루는 사용자는 바로 업그레이드해야 한다. 영향 범위는 2026.11.11까지의 버전이다.

server-filesystem 2.4.0: 디렉터리 목록 검사 우회 수정
무엇 list_directory, list_directory_with_sizes, directory_tree, search_files가 디렉터리를 검사한 뒤 같은 디렉터리를 그대로 나열한다. 검사와 나열 사이에 디렉터리를 symlink로 바꿔치기해도 허용 디렉터리 밖의 항목 이름이 반환되지 않는다. 이 보호는 Linux와 macOS에만 적용되고, Windows는 아직 고정되지 않았다(#5600).
어떻게 쓰나 날짜 버전(2025.x, 2026.x) 사용자는 패키지 관리자가 2.4.0을 업그레이드로 제안하지 않는다. 직접 설치해야 한다: npm install @modelcontextprotocol/server-filesystem@2.4.0
의미 filesystem 서버를 쓰는 사용자에게 의미가 있다. 날짜 버전을 쓰고 있다면 명시적으로 설치해야 한다. Windows에서는 이 수정이 적용되지 않는다.

memory 서버 쓰기 제한 옵션과 lock 처리 개선
무엇 server-memory 2.2.1에 그래프 크기에 대한 opt-in 쓰기 제한이 추가됐다(#5534). 종료나 SIGINT/SIGTERM 때 잡고 있던 lock 파일을 풀고, stale lock을 깰 때 다른 프로세스의 살아 있는 lock을 지우지 않게 했다. Streamable HTTP 서버가 멈출 때도 lock을 푼다.

의미 memory 서버를 장기간 돌리거나 여러 프로세스에서 쓰는 사용자에게 도움이 된다.
